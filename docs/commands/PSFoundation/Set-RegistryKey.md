# Set-RegistryKey

## SYNOPSIS

Creates a registry key if it does not already exist.

## SYNTAX

### __AllParameterSets

```
Set-RegistryKey [-Path] <string> [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Attempts to create the registry key at the given path.
If the key already
exists the operation is skipped.
Returns a status object indicating
whether the key was created or already present.

## EXAMPLES

### Example 1

```powershell
Set-RegistryKey -Path 'HKLM:\Software\MyApp'
```
