# Install-Win32ProgramFromWinGet

## SYNOPSIS

Installs a Win32 program through the Microsoft.WinGet.Client provider.

## SYNTAX

### Name

```
Install-Win32ProgramFromWinGet -Name <string> [-Version <string>] [-Source <string>] [-DryRun]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

### Id

```
Install-Win32ProgramFromWinGet -Id <string> [-Version <string>] [-Source <string>] [-DryRun]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Uses Microsoft.WinGet.Client when available to install an application by
name or exact package ID.
The winkit function name is intentionally
Win32ProgramFromWinGet so it does not shadow provider cmdlets exported by
Microsoft.WinGet.Client.

## EXAMPLES

### Example 1

```powershell
Install-Win32ProgramFromWinGet -Id 'Microsoft.VisualStudioCode'
```

### Example 2

```powershell
Install-Win32ProgramFromWinGet -Name 'Visual Studio Code' -DryRun
```
