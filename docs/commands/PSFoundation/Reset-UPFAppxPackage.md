# Reset-UPFAppxPackage

## SYNOPSIS

Resets app data for installed UPF AppX/MSIX packages when the platform supports it.

## SYNTAX

### __AllParameterSets

```
Reset-UPFAppxPackage [-Name] <string> [-DryRun] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Resolves installed packages by name and calls the platform
Reset-AppxPackage cmdlet when it is available.
The helper does not delete
package folders manually; unsupported platforms return a skipped result.

## EXAMPLES

### Example 1

```powershell
Reset-UPFAppxPackage -Name 'Microsoft.GetHelp'
```
