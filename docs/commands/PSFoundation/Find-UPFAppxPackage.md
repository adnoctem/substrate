# Find-UPFAppxPackage

## SYNOPSIS

Resolves UPF AppX/MSIX wildcard patterns to concrete package inventory records.

## SYNTAX

### __AllParameterSets

```
Find-UPFAppxPackage [-Pattern] <string[]> [-Installed] [-Provisioned] [-AllUsers]
 [-IncludeProtected] [-IncludeFramework] [-IncludeResource] [-IncludeBundle] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Looks up installed and/or provisioned AppX/MSIX packages for each pattern
and annotates every result with match and protection metadata.
Unmatched
patterns are returned as structured records so removal scripts can report
what did and did not resolve.

## EXAMPLES

### Example 1

```powershell
Find-UPFAppxPackage -Pattern 'Microsoft.Zune*' -Installed
```

### Example 2

```powershell
'Microsoft.GetHelp','Microsoft.BingWeather*' | Find-UPFAppxPackage -Installed
```
