# Remove-RegistryKey

## SYNOPSIS

Removes a registry key and optionally its subkeys.

## SYNTAX

### __AllParameterSets

```
Remove-RegistryKey [-Path] <string> [-Recurse] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Deletes the registry key at the given path.
When -Recurse is specified,
all descendant subkeys are removed as well.
If the key does not exist the
operation is skipped.
Returns a status object indicating whether the key
was removed or was already absent.

## EXAMPLES

### Example 1

```powershell
Remove-RegistryKey -Path 'HKLM:\Software\MyApp'
```

### Example 2

```powershell
Remove-RegistryKey -Path 'HKLM:\Software\MyApp' -Recurse
```
