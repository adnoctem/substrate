# New-OfficeDeploymentConfiguration

## SYNOPSIS

Creates an ordered, secret-free Office target configuration in memory.

## SYNTAX

### __AllParameterSets

```
New-OfficeDeploymentConfiguration [-TargetProductId] <string> [[-Architecture] <string>]
 [[-Channel] <string>] [[-Language] <string[]>] [[-Version] <string>] [[-ExcludeApp] <string[]>]
 [[-LocaleSource] <string>] [-AutoSourceLocales] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Defaults to en-us regardless of the execution account.
Automatic locale
discovery is explicit.
This object grants no authority to change a machine.

## EXAMPLES

### Example 1

```powershell
New-OfficeDeploymentConfiguration -TargetProductId Standard2024Volume -Language en-us,de-de
```
