# Update-UPFAppxPackage

## SYNOPSIS

Updates a package using a local AppX/MSIX file.

## SYNTAX

### __AllParameterSets

```
Update-UPFAppxPackage [-Path] <string> [[-DependencyPath] <string[]>] [-DryRun] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Reuses the native install operation with explicit version replacement.

## EXAMPLES

### EXAMPLE 1

```powershell
Update-UPFAppxPackage -Path '.\Example.msix' -DryRun
```
