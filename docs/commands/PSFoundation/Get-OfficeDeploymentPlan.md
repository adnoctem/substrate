# Get-OfficeDeploymentPlan

## SYNOPSIS

Builds a read-only Office operation plan with explicit authority.

## SYNTAX

### __AllParameterSets

```
Get-OfficeDeploymentPlan [-Action] <string> [[-Configuration] <Object>] [[-SourcePath] <string>]
 [[-RemoveProductId] <string[]>] [[-Language] <string[]>] [[-Settings] <Object>]
 [[-Inventory] <Object>] [-RemoveMsi] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

C# evaluates the requested scope and observations.
PowerShell retains schema validation, media discovery and the existing fingerprint format.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-OfficeDeploymentPlan -Action Install -Configuration $target -SourcePath C:\Media\Office
```
