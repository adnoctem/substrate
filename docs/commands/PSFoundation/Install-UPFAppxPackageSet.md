# Install-UPFAppxPackageSet

## SYNOPSIS

Installs a sequence of local AppX/MSIX packages.

## SYNTAX

### __AllParameterSets

```
Install-UPFAppxPackageSet [-Path] <string[]> [[-DependencyPath] <string[]>] [-Provisioned]
 [-SkipLicense] [-ForceUpdateFromAnyVersion] [-PassThru] [-DryRun] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Applies the singular native install operation with the same confirmation and result handling.

## EXAMPLES

### EXAMPLE 1

```powershell
Install-UPFAppxPackageSet -Path '.\One.msix', '.\Two.msix' -PassThru -DryRun
```
