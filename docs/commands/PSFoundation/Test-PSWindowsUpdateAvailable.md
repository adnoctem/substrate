# Test-PSWindowsUpdateAvailable

## SYNOPSIS

Returns $true if the PSWindowsUpdate module is installed.

## SYNTAX

### __AllParameterSets

```
Test-PSWindowsUpdateAvailable [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Checks Get-Module -ListAvailable.
Does not import the module.

## EXAMPLES

### Example 1

```powershell
Test-PSWindowsUpdateAvailable
```
