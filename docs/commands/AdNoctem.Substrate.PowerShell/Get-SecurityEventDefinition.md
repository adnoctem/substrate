# Get-SecurityEventDefinition

## SYNOPSIS

Finds event definitions using the C# event catalog.

## SYNTAX

### __AllParameterSets

```
Get-SecurityEventDefinition [[-Group] <string>] [[-LogName] <string>] [[-ProviderName] <string>]
 [[-Id] <int[]>] [[-Name] <string>] [[-Configuration] <hashtable>] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Preserves original definition hashtables and optional filters.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SecurityEventDefinition -Group Logon -Id 4624
```
