# Import-SecurityEventConfiguration

## SYNOPSIS

Reads and caches literal security event configuration data.

## SYNTAX

### __AllParameterSets

```
Import-SecurityEventConfiguration [[-Path] <string>] [-Force] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Keeps the module-local cache while C# parses the data without executing expressions.

## EXAMPLES

### EXAMPLE 1

```powershell
Import-SecurityEventConfiguration -Force
```
