# Remove-RegistryValue

## SYNOPSIS

Removes a named value from a registry key.

## SYNTAX

### __AllParameterSets

```
Remove-RegistryValue [-Path] <string> [[-Name] <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Deletes the named value from the registry key at the given path.
If the
value does not exist the operation is skipped.
Returns a status object
indicating whether the value was removed or was already absent.

## EXAMPLES

### Example 1

```powershell
Remove-RegistryValue -Path 'HKLM:\Software\MyApp' -Name 'Version'
```
