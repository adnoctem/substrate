# Repair-UPFAppxPackage

## SYNOPSIS

Repairs installed UPF AppX/MSIX packages by re-registering their manifests.

## SYNTAX

### __AllParameterSets

```
Repair-UPFAppxPackage [-Name] <string> [-AllUsers] [-DryRun] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Resolves installed packages by name and runs Add-AppxPackage -Register
against each package's AppxManifest.xml.
This is useful for restoring
package registrations without deleting app data.

## EXAMPLES

### Example 1

```powershell
Repair-UPFAppxPackage -Name 'Microsoft.WindowsStore'
```

### Example 2

```powershell
Repair-UPFAppxPackage -Name 'Microsoft.DesktopAppInstaller*' -DryRun
```
