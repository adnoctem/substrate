# Uninstall-UPFAppxPackageSet

## SYNOPSIS

Resolves package patterns and removes eligible AppX/MSIX packages.

## SYNTAX

### __AllParameterSets

```
Uninstall-UPFAppxPackageSet [-Pattern] <string[]> [-Installed] [-Provisioned] [-AllUsers]
 [-IncludeProtected] [-Force] [-PassThru] [-DryRun] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Uses the native discovery and singular removal APIs.
Protected removals require both IncludeProtected and Force.

## EXAMPLES

### EXAMPLE 1

```powershell
Uninstall-UPFAppxPackageSet -Pattern 'Microsoft.Zune*' -DryRun -PassThru
```
