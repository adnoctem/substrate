# Install-Win32Program

## SYNOPSIS

Runs a caller-selected local installer through the C# package API.

## SYNTAX

### __AllParameterSets

```
Install-Win32Program [-Path] <string> [[-ArgumentList] <string[]>] [[-SuccessExitCodes] <int[]>]
 [[-RebootExitCodes] <int[]>] [[-RunId] <string>] [-NoWait] [-PassThru] [-DryRun] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Retains PowerShell path validation, confirmation and result fields.
Preparation and execution are provided by C#.

## EXAMPLES

### EXAMPLE 1

```powershell
Install-Win32Program -Path '.\setup.exe' -ArgumentList '/quiet' -WhatIf
```
