# Set-ItemOwner

## SYNOPSIS

Set-ItemOwner - Takes ownership of a file or folder via takeown/icacls.

## SYNTAX

### __AllParameterSets

```
Set-ItemOwner [-Path] <string> [-Group <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Takes ownership of the specified filesystem object (file or directory) and grants
FullControl to the specified group, using takeown.exe and icacls.exe shell-outs.

For directories the operation recurses through all children.
When takeown/icacls
fail (e.g.
genuinely stuck items), a robocopy /purge fallback is attempted against
an empty staging folder - note that this DELETES the target's contents and is a
last-resort path.

Requires elevation.

## EXAMPLES

### Example 1

```powershell
Set-ItemOwner -Path 'C:\Program Files\VendorApp'
```
