# Enable-WSLFirewallRule

## SYNOPSIS

Ensures the inbound WSL firewall allow rule exists.

## SYNTAX

### __AllParameterSets

```
Enable-WSLFirewallRule [[-DisplayName] <string>] [[-InterfaceAlias] <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Adds a Windows Firewall rule allowing inbound traffic on the WSL virtual
Ethernet adapter.
Existing rules with the same display name are treated as
already configured to avoid creating duplicates.

## EXAMPLES

### Example 1

```powershell
Enable-WSLFirewallRule
```
