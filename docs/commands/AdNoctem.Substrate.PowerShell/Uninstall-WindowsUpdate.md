# Uninstall-WindowsUpdate

## SYNOPSIS

Uninstalls a previously installed Windows update.

## SYNTAX

### __AllParameterSets

```
Uninstall-WindowsUpdate [-KBArticleID] <string> [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Uninstalls matching installed updates through Windows Update Agent.
Requires a KBArticleID.
Asks for confirmation
by default since removing security updates can leave the system
vulnerable.

## EXAMPLES

### Example 1

```powershell
Uninstall-WindowsUpdate -KBArticleID 'KB5021233'
```
