# Add-PSModule

## SYNOPSIS

Installs PowerShell modules.

## SYNTAX

### __AllParameterSets

```
Add-PSModule [[-Name] <string>] [[-Version] <string>] [[-MinimumVersion] <string>]
 [[-Scope] <string>] [[-FromFile] <string>] [-Force] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Installs a single module by name, or restores all modules from a JSON
file previously exported by Get-PSModule.

Uses the installed PSResourceGet provider when available, otherwise PowerShellGet.
The repository provider must already be installed and configured; this command does not bootstrap providers or change repository trust.

## EXAMPLES

### Example 1

```powershell
Add-PSModule -Name Pester -Version '5.4.0'
```

Installs Pester 5.4.0 to the CurrentUser scope.

### Example 2

```powershell
Add-PSModule -FromFile ./modules.json -Force
```

Restores all modules listed in modules.json, forcing reinstall.
