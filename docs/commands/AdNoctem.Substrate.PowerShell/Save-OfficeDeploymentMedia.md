# Save-OfficeDeploymentMedia

## SYNOPSIS

Prepares a verified Office package and publishes its manifest last.

## SYNTAX

### __AllParameterSets

```
Save-OfficeDeploymentMedia [-Configuration] <Object> [-SourcePath] <string> [-OdtPath] <string>
 [-DryRun] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Downloads only during explicit preparation.
C# verifies and publishes the package without replacing incomplete or incompatible media.

## EXAMPLES

### EXAMPLE 1

```powershell
Save-OfficeDeploymentMedia -Configuration $target -SourcePath C:\Media\Office -OdtPath C:\ODT\setup.exe -WhatIf
```
