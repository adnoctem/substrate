# Get-UPFAppxPackage

## SYNOPSIS

Returns normalized installed and provisioned UPF AppX/MSIX package inventory.

## SYNTAX

### __AllParameterSets

```
Get-UPFAppxPackage [[-Name] <string>] [-Installed] [-Provisioned] [-AllUsers] [-IncludeFramework]
 [-IncludeResource] [-IncludeBundle] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Combines Windows package-manager and DISM inventory into a common object
shape so callers can reason about installed user packages and provisioned
Windows image packages together.
Framework, resource, and bundle packages
are hidden by default to keep normal inventory focused on user-facing apps.

## EXAMPLES

### Example 1

```powershell
Get-UPFAppxPackage -Name 'Microsoft.GetHelp'
```

### Example 2

```powershell
Get-UPFAppxPackage -Name 'Microsoft.Bing*' -Installed -Provisioned
```
