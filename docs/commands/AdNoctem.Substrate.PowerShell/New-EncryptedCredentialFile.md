# New-EncryptedCredentialFile

## SYNOPSIS

Stores a credential and a separate random AES key in protected files.

## SYNTAX

### __AllParameterSets

```
New-EncryptedCredentialFile [-Path] <string> [-KeyPath] <string> [[-Credential] <pscredential>]
 [[-UserName] <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Uses the compatible v1 file format.
Restricts access before writing secret
bytes.
The caller must control both parent directories.
The two file
replacements are not transactional; recreate the pair after a partial failure.

## EXAMPLES

### EXAMPLE 1

```powershell
New-EncryptedCredentialFile -Path '.\credential.bin' -KeyPath '.\credential.key' -Credential (Get-Credential)
```
