# Uninstall-UPFAppxPackage

## SYNOPSIS

Uninstalls a single normalized UPF AppX/MSIX package inventory record.

## SYNTAX

### __AllParameterSets

```
Uninstall-UPFAppxPackage [-InputObject] <psobject> [-AllUsers] [-IncludeProtected] [-Force]
 [-DryRun] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Removes one installed or provisioned package object produced by
Get-UPFAppxPackage or Find-UPFAppxPackage.
Protected packages are skipped
unless both -IncludeProtected and -Force are supplied.

## EXAMPLES

### Example 1

```powershell
Find-UPFAppxPackage -Pattern 'Microsoft.ZuneMusic' -Installed | Where-Object Matched | ForEach-Object Package | Uninstall-UPFAppxPackage -DryRun
```
