# Uninstall-Win32ProgramFromWinGet

## SYNOPSIS

Uninstalls a Win32 program through the Microsoft.WinGet.Client provider.

## SYNTAX

### Name

```
Uninstall-Win32ProgramFromWinGet -Name <string> [-DryRun] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### Id

```
Uninstall-Win32ProgramFromWinGet -Id <string> [-DryRun] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Uses Microsoft.WinGet.Client when available to uninstall an application by
name or exact package ID.
The wrapper returns winkit lifecycle result
objects while avoiding command-name collisions with the provider module.

## EXAMPLES

### Example 1

```powershell
Uninstall-Win32ProgramFromWinGet -Id 'Microsoft.OneDrive' -DryRun
```

### Example 2

```powershell
Uninstall-Win32ProgramFromWinGet -Name 'Microsoft OneDrive'
```
