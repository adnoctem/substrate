# Get-WindowsServiceEvent

## SYNOPSIS

Queries service lifecycle, failure, and installation events.

## SYNTAX

### __AllParameterSets

```
Get-WindowsServiceEvent [[-StartTime] <datetime>] [[-EndTime] <datetime>] [[-Id] <int[]>]
 [[-ServiceName] <string>] [[-ComputerName] <string[]>] [[-MaxEvents] <int>]
 [[-Configuration] <hashtable>] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Wraps Get-WindowsEventByDefinition for the Service group.
Supports
filtering by service name and event ID.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-WindowsServiceEvent -Id 7045
```

Returns new service installation events (common persistence vector).
