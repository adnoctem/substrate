# Get-SecurityEventGroup

## SYNOPSIS

Gets a named security event group.

## SYNTAX

### __AllParameterSets

```
Get-SecurityEventGroup [-Name] <string> [[-Configuration] <hashtable>] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Resolves the group from the supplied or cached configuration through C#.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SecurityEventGroup -Name Logon
```
